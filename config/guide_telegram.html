AUTO-COC Telegram

Use this guide to connect Telegram remote control.

1. Quick setup

  1. Open @BotFather and send /newbot.
  2. Copy the token and keep it private.
  3. Open the bot and send /start.
  4. In AUTO-COC, open Settings → Configure Telegram, enter the token and allowed chat ID, then save.

2. Controls

The inline controls provide:

  • Run, Stop, Launch CoC and Screenshot.
  • Choose macro to select any editable macro.
  • Reload CoC and Validate arrival, linked to the assigned system-role macros.
  • Settings for loop playback and shutdown confirmation.

3. Troubleshooting

  • Make sure the token is valid and the bot was started.
  • Use the numeric chat ID of the authorized conversation.
  • Only one AUTO-COC instance should poll Telegram at a time.
  • Open Diagnostics to inspect the recent activity log.

4. Security

Never share the bot token or commit config/data.csv. If the token is exposed, revoke it with BotFather and create a new one.
