1. Concepts clés

  • Bot Telegram : un compte automatisé que vous pilotez via l’API Bot.
  • Token : secret donné par @BotFather pour authentifier votre bot.
  • chat_id : identifiant numérique d’un chat privé ou d’un groupe où le bot enverra des messages.
  • Polling : l’app interroge régulièrement l’API via getUpdates. Ne pas utiliser en même temps qu’un webhook.

2. Créer le bot avec @BotFather

  1. Ouvrez @BotFather dans Telegram.
  2. Envoyez /newbot, définissez un nom et un username se terminant par bot.
  3. Copiez le token affiché. Conservez-le en sécurité.
  4. Si besoin, régénérez le token avec /revoke puis /token sur BotFather.

Documentation : core.telegram.org/bots • API : core.telegram.org/bots/api

3. Récupérer votre chat_id

  1. Parlez à votre bot : cliquez le lien fourni par BotFather puis envoyez /start.
  2. Fermez l’app Macro COC si elle tourne.
  3. Dans votre navigateur, ouvrez :
    https://api.telegram.org/bot<VOTRE_TOKEN>/getUpdates
  4. Trouvez le champ chat dans la réponse JSON et copiez id (valeur numérique).
{
  "ok": true,
  "result": [{
    "update_id": 123456789,
    "message": {
      "chat": { "id": 1234567890, "type": "private", "first_name": "Vous" },
      "text": "/start"
    }
  }]
}

Conflit 409 ? Supprimez un éventuel webhook : https://api.telegram.org/bot<TOKEN>/deleteWebhook

4. Configurer l’application Macro COC

  1. Ouvrez l’app → Paramètres → Automatisation Telegram.
  2. Collez votre token et votre chat_id. Cliquez Enregistrer.
  3. Au démarrage, l’app purge le backlog Telegram et affiche un clavier inline dans votre chat.
Astuce : activez ou non la lecture en boucle depuis Paramètres ou depuis Telegram (voir section 5).

6. Tests API rapides

curl

curl -s "https://api.telegram.org/bot<TOKEN>/getMe"
curl -s "https://api.telegram.org/bot<TOKEN>/sendMessage" -d "chat_id=<CHAT_ID>&text=Hello"

PowerShell

$uri = "https://api.telegram.org/bot<TOKEN>/sendMessage"
Invoke-RestMethod -Uri $uri -Method Post -Body @{ chat_id="<CHAT_ID>"; text="Hello" }

Envoyer une photo (multipart, curl)

curl -s -F "chat_id=<CHAT_ID>" -F "photo=@screenshot.png" \
  "https://api.telegram.org/bot<TOKEN>/sendPhoto"

Si aucune mise à jour ne remonte, envoyez un message au bot, attendez 2–3 s puis relancez getUpdates.

8. Sécurité et bonnes pratiques

  • Ne partagez jamais votre token. Traitez-le comme un mot de passe.
  • En cas de doute, révoquez le token sur @BotFather et mettez à jour l’app.
  • Évitez de publier data.csv avec le token sur un dépôt public.
  • Si vous activez des captures automatiques, vérifiez ce qui peut apparaître à l’écran.
